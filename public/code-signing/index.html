SECURITY · CODE SIGNING POLICY

Code signing policy

How the Axell plugins and the Dojo are built, signed and checked, so you can trust that a download is exactly what was published from the open source code. As of 20 November 2026.

1. What is built, and where

Every release is built from the public source code on GitHub (GNU AGPLv3). The Windows files - the nine plugins (.vst3), the Axell Signature Dojo and the Axell Signature Suite installer - are built only by GitHub Actions, from the commit and tag named in each release, and tested there (the plugins' own test suites, pluginval at strictness 10, a sound match with the Linux build). The Linux archives are built on Ubuntu 22.04 from the same tag.

2. Windows code signing

Windows code signing is being set up with the SignPath Foundation, which signs open source software for free. Until that is in place, the Windows files are not code-signed, and Windows SmartScreen may show "Windows protected your PC" for the suite installer (choose More info, then Run anyway). Once it is active, signed releases carry: Free code signing provided by SignPath.io, certificate by SignPath Foundation. Only builds from GitHub Actions are ever submitted for signing, and every signing request is approved by hand.

3. Team and roles

The Axell suite is made by one person, Axell Yobag (github.com/zmardanian), who holds every role:

  • Committers and reviewers: Axell Yobag. Changes proposed by anyone else (pull requests) are reviewed before they are merged.
  • Approvers: Axell Yobag approves every release and every signing request.

The GitHub account uses two-factor authentication, and the release branches and tags are protected against deletion and rewriting.

4. Checking a download yourself

Every release has a SHA256SUMS.txt with the fingerprint of each file, and from 20 November 2026 a SHA256SUMS.txt.minisig that signs it with the suite's release key (minisign). The public key:

RWQJLVJSETsP7RRz1rdiugX9w09wtGCtwEc5hHU8k9S+crL/ekfTkQKG

On Linux: minisign -Vm SHA256SUMS.txt -P RWQJLVJSETsP7RRz1rdiugX9w09wtGCtwEc5hHU8k9S+crL/ekfTkQKG, then sha256sum -c --ignore-missing SHA256SUMS.txt. On Windows (PowerShell): Get-FileHash <file> and compare it with the line in SHA256SUMS.txt. The suite installer also carries a GitHub build attestation: gh attestation verify <file> -R zmardanian/axell-signature-dojo. The Axell Signature Dojo checks the fingerprint of every download before it installs anything.

5. Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The plugins never connect to the internet. The Dojo contacts GitHub (api.github.com and github.com) only when you click to check for updates or to install, to read the list of releases and download them; it sends nothing about you or your computer. See the privacy policy for this website.

6. Reporting a problem

Security problems: please report them privately - see the security policy in each repository, or write to contact@axellsdojo.com.
